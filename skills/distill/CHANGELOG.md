- Three output types: Skill, Specialist, SOP
- Lean SKILL.md entry point with references/ architecture
- WIZARD.md — full wizard flow, Q&A framework, edge cases
- TEMPLATES.md — output templates for all three package types
- Multi-pattern session support
- Adaptive Q&A that skips irrelevant questions
- Cross-linking for related patterns packaged in the same session
